# 📸 BeautifulScreenShot - Java Desktop Screenshot Tool

  **BeautifulScreenShot** is a Java Swing-based desktop application that allows users to capture their screen either as a **full-screen snapshot** or using a **snipping tool**. It also supports delay-based captures and includes a preview of the screenshot taken.

## 🚀 Features
    📅 **Timed Screenshots**: Set a custom delay before capturing.
    🖥️ **Full-Screen or Snip Mode**: Choose between full-screen or manual snip capture.
    🗂️ **Auto-Save with Timestamp**: Screenshots are saved automatically with the current date and time.
    🖼️ **Live Preview**: Shows a scaled-down preview of the captured image.
    📊 **Progress Bar & Countdown**: Visual feedback while waiting for capture.
    ❌ **Cancel Option**: Cancel screenshot anytime before the timer ends.
